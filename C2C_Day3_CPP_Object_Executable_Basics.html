Three file stages

The source file. This is where programmers write C++ instructions.

An object file produced by compiling source code. It is not usually run directly.

Code component

What is #include <iostream>?

Include a standard header

iostream provides common input/output tools, such as cout for output and cin for input.

The #include line is a preprocessor directive. It tells the preprocessor to include the header's contents in the compilation process.
Header files provide declarations and tools05 / 18
Code component

What is using namespace std;?

Many C++ standard-library names live inside the std namespace.

With namespace declaration

using namespace std; cout << "Hello";

Without it

std::cout << "Hello";
std is short for the standard namespace. The declaration allows us to use many standard names without repeatedly writing std::. In larger projects, explicit std:: is often preferred to avoid name conflicts.

Code component

What is main()?

main() is the special function where execution of a typical C++ program begins.

When the program starts, execution begins in main(). Statements inside its braces are executed according to the program's flow.

Concept · Data

What is a data type?

A data type describes the kind of value a variable can hold and helps determine how that value is represented and used.

Numbers

Whole numbers or values with fractional parts.

Characters

A single character such as 'A'.

Boolean

True or false values.

Text

Strings such as "Hello".

Choosing a type helps the compiler understand how to store and work with values.

Concept · Integers

int — whole numbers

The int type is commonly used for whole-number values, without a fractional part.

int age = 18; int students = 35; int temperature = -4;

Examples

0, 7, 42, -12

Not examples of an integer value

3.14, 8.75 — these have fractional parts.

Integer types come in different sizes and signed/unsigned forms. For now, use int for ordinary whole-number examples.
Integer basics12 / 18
Concept · Floating-point

float vs decimal values

A decimal number is a way we write a number. float is a C++ data type used to represent fractional numbers using floating-point representation.

float

Usually stores about 6–7 decimal digits of precision. It uses less memory than double on many systems.

float price = 12.5f;

double

Usually stores about 15–16 decimal digits of precision. Often the default choice for fractional calculations.

double pi = 3.1415926535;
Important: C++ does not have a built-in type named decimal in the core language. float and double store binary floating-point approximations, so some decimal fractions cannot be represented exactly. For example, 0.1 may not be stored as an exact value.
Precision is not the same as the number of digits shown13 / 18
Concept · More types

Other beginner data types

char

Represents a character, often written with single quotes.

char grade = 'A';

bool

Represents a Boolean value: true or false.

bool isReady = true;

string

Represents text. Include <string> or use it through the standard library.

string name = "Aman";

double

Floating-point type often used when more precision is desired than float.

double distance = 12.345;

Concept · Variables

Variables store values

A variable is a named location that we use to work with a value in our program.

int age = 20; double height = 1.75; char grade = 'A'; bool passed = true; string name = "Student";
A declaration tells the compiler the variable's type and name. An assignment gives it a value.
