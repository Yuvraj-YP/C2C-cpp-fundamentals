Day 02 · Flowchart Foundations

Standard Symbols & Loop Arrows

Every flowchart is a directed map. Using the exact shape tells the reader whether a step reads data, computes, branches, or repeats.

Terminator (Oval)

Marks entry and exit points of the algorithm.

Input / Output

Parallelogram: cin (reading) or cout (printing).

Process (Rectangle)

Calculations, variable updates, and assignments.

Decision (Diamond)

Evaluates a boolean condition with labeled Yes / No exits.

How a Loop Works in a Flowchart (Backward Flow Arrow)

A loop is simply a Decision Diamond whose YES branch executes a Process block and then draws an upward arrow back above the diamond to re-test the condition! Without an update step inside the loop, the upward arrow creates an infinite loop.

4 Parts of Every Loop: 1. Initialize counter → 2. Test condition (Diamond) → 3. Body & Update counter → 4. Loop-back arrow to Step 2.
Remember: Outputs always use Parallelograms, never Rectangles02 / 14

Day 03 · Pre-Compile Architecture Gate

Before You Enter the Compile Screen:
How g++ Builds Your Program

A computer CPU cannot directly execute human-written C++ text. When you click Run or execute g++ main.cpp -o main.exe, your code passes through three essential file stages:

1. Source File
main.cpp
──(Compiler)──▶
2. Object File
main.o
──(Linker)──▶
3. Executable File
main.exe
Terminal Commands Behind the Scenes:
g++ -c main.cpp -o main.o (Compile Source File into Object File)  |  g++ main.o -o main.exe (Link Object File + C++ Standard Library into Executable File)

Day 03 · Build Files Explained

Source File (.cpp), Object File (.o) & Executable (.exe)

Every C++ student should know what each file contains and why an Object File cannot run on its own before Linking.

File Type Extension Created By Human Readable? What Is Inside & Why It Exists
Source File .cpp You (Code Editor) Yes (C++ code) Your human-written C++ program containing #include <iostream>, variables, logic, and int main().
Object File .o / .obj Compiler
(g++ -c main.cpp)		 No (Binary machine code) Checks syntax & types, expands headers, and translates your C++ logic into raw CPU machine code (0s and 1s)—but external library calls like std::cout still have unresolved placeholder addresses.
Executable File .exe Linker
(g++ main.o -o main.exe)		 No (OS-ready binary) Connects your main.o with C++ Standard Library binaries (libstdc++), resolves all memory addresses, attaches OS startup headers, and produces a runnable program.
Compiler Error vs. Linker Error: Missing semicolon ; or wrong variable type → caught when building the Object File (.o). Calling a declared function whose body was never written → caught when building the Executable File (.exe) as undefined reference!

Day 03 · Session 03 · Blank-Screen Discipline

Anatomy of Your First C++ Program

Blank-screen discipline means typing every single line from memory—never copy-pasting boilerplate—and knowing why every token exists.

#include <iostream> using namespace std; int main() { int a, b; cout << "Enter two numbers: "; cin >> a >> b; int sum = a + b; cout << "Sum = " << sum << "\n"; return 0; }

#include <iostream>

Brings in cin (standard input) and cout (standard output) declarations so the compiler knows how to check them.

int main() { ... }

Mandatory entry point where the OS begins executing main.exe. Every statement inside ends with a semicolon ;.

cin >> vs. cout <<

>> extracts data from keyboard into a variable; << inserts data onto the screen.

return 0;

Signals to the operating system that main.exe finished cleanly with zero errors.

Rule: Never copy-paste your starter template during Week 109 / 14
Day 03 · Core Data Types & Memory Sizes

Mastering Essential C++ Data Types

Choosing the right data type prevents silent integer overflow, truncated decimals, and wasted memory.

Data Type Typical Size What It Stores Example Declaration When to Choose It
int 4 bytes (32-bit) Whole numbers (~ −2.14×109 to +2.14×109) int count = 42; Default for counters, indices, and numbers up to 109.
long long 8 bytes (64-bit) Large integers (~ −9.22×1018 to +9.22×1018) long long pop = 8000000000LL; Sums, products, or populations exceeding 2 billion.
double 8 bytes (64-bit) Floating-point decimals (~15 digits precision) double avg = 87.65; Averages, percentages, prices, and scientific values.
char 1 byte (8-bit) Single ASCII character in single quotes char grade = 'A'; Single letters, digits, or symbols ('A', '7', '+').
bool 1 byte (8-bit) Logical truth value: true (1) or false (0) bool isPrime = true; Condition flags, loop guards, and decision outcomes.
Classic Day-03 Trap — Integer Division: In C++, 5 / 2 evaluates to 2 (both operands are int). Write 5.0 / 2 or (double)a / b to get 2.5!

Day 03 · Blank-Screen Practice Lab

Drill: Write a Complete C++ Program from Scratch

Task: Read three integer marks from the user, compute their exact decimal average using double, and print the result.

Checklist Before You Reveal

  • Include <iostream> and using namespace std;
  • Declare int m1, m2, m3; and read them with cin >>
  • Avoid integer truncation by dividing by 3.0
  • Output the average with cout <<
  • End main() with return 0;
Mental Check: Trace how g++ builds your code: Source (.cpp) → Object (.o) → Executable (.exe).
#include <iostream> using namespace std; int main() { int m1, m2, m3; cin >> m1 >> m2 >> m3; double avg = (m1 + m2 + m3) / 3.0; cout << "Average = " << avg << "\n"; return 0; }

Day 02 & Day 03 · Quick Reference

Master Cheat Sheet for Revision

Flowchart Rules (Day 02)

Oval: Start / End
Parallelogram: Input & Output (both cin & cout)
Rectangle: Arithmetic & Variable Assignment
Diamond: Condition (Yes / No)
Loop: Process updates counter → arrow loops back above Diamond.

g++ Build Files (Day 03)

Source File (.cpp): Human-written C++ code.
Object File (.o): Compiler output—binary machine code for your file, with external library calls like std::cout still unlinked.
Executable File (.exe): Linker output—combines .o with C++ Standard Library & OS startup code into a runnable program.

Essential Data Types

int (4B), long long (8B), double (8B), char (1B), bool (1B). Divide by 3.0 (not 3) for decimal averages.
