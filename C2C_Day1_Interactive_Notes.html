Concept 01

What is an algorithm?

An algorithm is a finite, ordered set of clear instructions that solves a problem or completes a task.

01 Clear

Each instruction should have one understandable meaning.

02 Ordered

Steps must be arranged in the sequence in which they should happen.

03 Finite

The algorithm must eventually stop, not continue forever.

04 Effective

Steps should be practical and capable of being carried out.

Everyday example: Making tea is an algorithm when you describe its steps in a clear order.
Think of an algorithm as a recipe for solving a problem.02 / 12

Concept 03

Pseudocode: logic without syntax

Pseudocode is a readable, programming-style description of an algorithm. It is not tied to a specific programming language.

Useful conventions

  • START / END: boundaries of the algorithm
  • INPUT / READ: collect data
  • SET: assign or calculate
  • IF / ELSE: express decisions
  • OUTPUT / PRINT: display results

Example structure

START INPUT data PROCESS data OUTPUT result END
Remember: Prioritize clarity. Pseudocode should be easy for a human to trace, even if its wording isn't valid C++.

Worked example

Calculate a shopping total

Problem: Given the price of three items, calculate and display their combined total.

Inputs

Price A, Price B, Price C

Processing

Total = A + B + C

Output

The combined amount

Assumption

Prices are numeric and supplied in the same currency.

START INPUT priceA INPUT priceB INPUT priceC SET total = priceA + priceB + priceC OUTPUT total END
Notice how the steps are simple and unambiguous.05 / 12

Concept 04 · Visual logic

Introduction to flowcharts

A flowchart is a visual representation of an algorithm. It uses standard shapes connected by arrows to show the sequence of steps, decisions and data flow.

Why use flowcharts?

Make logic visible, communicate a solution, spot missing steps, and plan before writing code.

How to read one

Follow the arrows, usually from top to bottom or left to right. A flowchart should have a clear start and end.

Flowchart = algorithm's visual map. Pseudocode describes the steps in words; a flowchart shows the steps and their connections.
Flowcharts visualize sequence and control flow.09 / 12
Concept 05 · Symbols

The essential flowchart symbols

🟢 Terminator · Start/End

Rounded oval: marks where a process begins or finishes.

🔷 Process

Rectangle: calculation, assignment or action.

🟦 Input / Output

Parallelogram: read data or display information.

🔶 Decision

Diamond: test a condition and branch (e.g. Yes/No).

➡️ Flow line

Arrow: shows the direction and order of execution.

📄 Connector

Small circle or off-page connector: links separated flowchart sections when needed.

Common rule: Use arrows to connect symbols. Decision branches should be labelled, such as YES and NO.
Learn the shape, then learn what it represents.10 / 12
Worked example · Flowchart

Find whether a number is even or odd

Use a decision symbol to check whether a number is divisible by 2.

START → INPUT N → IF N % 2 = 0 → OUTPUT "EVEN"
ELSE → OUTPUT "ODD" → END
