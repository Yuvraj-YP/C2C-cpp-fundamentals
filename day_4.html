Core C++ Data Types Recap

Every variable in C++ reserves a fixed number of bytes in RAM. Choosing the right type prevents silent overflow and wasted precision.

Initial Revision · Quick Code Check

Data Types & Initialization Discipline

Uninitialized local variables hold garbage memory values. Always initialize variables at declaration and match literal suffixes to your target type.

Clean Declaration Habits

  • Initialize immediately: Use int count = 0; instead of leaving variables uninitialized.
  • Use LL suffix: Write 100000LL * 100000 so the compiler promotes to 64-bit arithmetic immediately.
  • Prefer double over float: float only gives ~6–7 digits of precision and rounds early.
  • ASCII awareness: '0' is 48, 'A' is 65, 'a' is 97.

Memory & Literal Demo

#include <iostream> using namespace std; int main() { int items = 50000; long long total = 1LL * items * items; double avg = total / 3.0; char grade = 'A'; bool isValid = (avg > 0); cout << total << " | " << avg << "\n"; return 0; }

Concept 01 · Operators

Arithmetic, Relational & Logical Operators

Operators transform values and combine conditions. Watch out for integer truncation and short-circuit evaluation.

Arithmetic (+ - * / %)

7 / 2 evaluates to 3 (truncates decimal). Modulo 7 % 2 returns remainder 1 and works only on integer types.

Increment / Decrement (++ --)

Prefix (++x): increments first, then uses the new value.
Postfix (x++): uses the current value first, then increments.

Relational (== != < > <= >=)

Always return a bool (true or false). Never confuse equality == with assignment =.

Logical (&& || !) & Short-Circuit

In A && B, if A is false, B is never evaluated. In A || B, if A is true, B is skipped.

Division Check: Checking b != 0 && a / b > 2 evaluates b != 0 first and skips a / b whenever b is zero.
Short-circuiting skips unnecessary right-hand evaluations.04 / 11
Concept 02 · Bit-Level Operations

Bitwise Operators Essentials

Bitwise operators work directly on the binary bits (0s and 1s) of integer types—fast, low-level, and essential for systems & DSA.

OperatorNameExample (a = 5 (0101), b = 3 (0011))Result
&Bitwise AND0101 & 0011 (1 only if both bits are 1)0001 (1)
|Bitwise OR0101 | 0011 (1 if either bit is 1)0111 (7)
^Bitwise XOR0101 ^ 0011 (1 if bits differ)0110 (6)
~Bitwise NOT~0101 (flips every bit)−6 (in signed 32-bit)
<<Left Shift5 << 1 (shifts left, multiplies by 21)1010 (10)
>>Right Shift5 >> 1 (shifts right, integer divides by 21)0010 (2)
Practical check: (n & 1) == 0 checks if n is even by inspecting its least significant bit. Never mix up bitwise & with logical &&!

Concept 04 · Type Conversions

Implicit Promotion vs. Explicit Casting

When mixed types meet in an expression, C++ promotes narrower types automatically—or lets you convert intentionally with static_cast.

Implicit Promotion Ladder

Automatically widens left to right during mixed expressions:

bool / char → int → long long → double
Trap: double ans = 5 / 2; evaluates 5 / 2 as int (2) first, and only then converts 2 to 2.0!

Explicit static_cast<T>

Safe, readable, compile-time checked casting:

int scored = 17, total = 20; // Wrong: integer division gives 0.0 double bad = (scored / total) * 100; // Right: cast numerator to double first double pct = static_cast<double>(scored) / total * 100; // pct = 85.0
Prefer static_cast<type>(val) over C-style (type)val.07 / 11

Day 04 Key Takeaways

Right-Size Types

Use long long before products exceed 2 × 109, and double for fractional precision.

Precedence & Associativity

Wrap mixed arithmetic, bitwise, and logical expressions in ( ) for clarity.

Explicit Casting

Cast one operand with static_cast<double> before dividing integers.

Bitwise vs. Logical

Use &, |, ^ for binary bit manipulation and &&, || for boolean conditions.
